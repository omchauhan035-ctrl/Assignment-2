=========================================================
  STEP 1 – TEST BOTH PROJECTS LOCALLY
=========================================================

For Q1 (Student Profile Card):
  1. Open terminal
  2. Go to: cd assignment-react-q1
  3. Run:    npm run dev
  4. Open browser at: http://localhost:5173
  5. Check that 6 student cards appear
  6. Click "Show Details" on each card to see email, phone, city

For Q2 (Text Analyzer):
  1. Open a NEW terminal (or stop Q1 first with Ctrl+C)
  2. Go to: cd assignment-react-q2
  3. Run:    npm run dev
  4. Open browser at: http://localhost:5173
  5. Type some text in the textarea
  6. Check character count and word count update live
  7. Check browser tab title changes as you type


=========================================================
  STEP 2 – CREATE GITHUB REPOSITORIES
=========================================================

Create TWO separate repositories on GitHub:

  Repo 1: assignment-react-q1
  Repo 2: assignment-react-q2

Steps for EACH repo:
  1. Go to https://github.com
  2. Click the "+" icon → "New repository"
  3. Name it (e.g. assignment-react-q1)
  4. Set to Public
  5. Do NOT initialize with README (we already have one)
  6. Click "Create repository"
  7. Copy the repo URL shown on screen


=========================================================
  STEP 3 – PUSH Q1 TO GITHUB
=========================================================

Open terminal and run these commands one by one:

  cd assignment-react-q1

  git init
  git add .
  git commit -m "Initial commit – Q1 Student Profile Card"
  git branch -M main
  git remote add origin https://github.com/YOUR_USERNAME/assignment-react-q1.git
  git push -u origin main

Replace YOUR_USERNAME with your actual GitHub username.


=========================================================
  STEP 4 – PUSH Q2 TO GITHUB
=========================================================

Open a new terminal and run:

  git init

  git commit -m "Initial commit – Q2 Text Analyzer"
  git branch -M main
  git remote add origin https://github.com/YOUR_USERNAME/assignment-react-q2.git

Replace YOUR_USERNAME with your actual GitHub username.


=========================================================
  STEP 5 – DEPLOY TO VERCEL
=========================================================

For EACH project:

  1. Go to https://vercel.com and sign in (use GitHub login)
  2. Click "Add New" → "Project"
  3. Import your GitHub repository
  4. Vercel will auto-detect it as a Vite project
  5. Click "Deploy" — no extra settings needed
  6. Wait ~1 minute for the live URL
  7. Copy the live URL (e.g. https://assignment-react-q1.vercel.app)
